# HCM_KS26_CNTT2_IT108_Session10_Ex03
# Phần 1: Phân tích bài toán
Token là đơn vị nhỏ mà AI sử dụng để xử lý văn bản. Markdown có cú pháp ngắn gọn hơn HTML nên thường sử dụng ít token hơn, giúp tiết kiệm chi phí API và giảm lượng dữ liệu cần xử lý. Tuy nhiên, tốc độ còn phụ thuộc vào mô hình AI và nội dung.
# Phần 2: So sánh Markdown và HTML
| Tiêu chí | markdown | html |
| :---: | :---:| :---: |
|số ký tự in đậm| ** text ** | <strong>text</strong>
|Độ dễ đọc| ngắn gọn, dễ đọc| nhiều thẻ, khó đọc hơn|
|hiệu quả sử dụng token| Thường ít token hơn, tiết kiệm chi phí| Có thể tốn nhiều token hơn|
# Phần 3: Giải pháp cho greentech 
 - Em chọn Markdown làm định dạng mặc định vì cú pháp đơn giản, dễ đọc, tiết kiệm token và phù hợp để AI hướng dẫn người nông dân chăm sóc cây trồng.
- HTML chỉ nên sử dụng khi cần xây dựng giao diện web phức tạp.
